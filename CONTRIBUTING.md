# Contributing

The contributor guide for this repo lives in [`AGENTS.md`](./AGENTS.md). It covers:

- Quick start (install, develop, verify, build).
- Pull request process and CI requirements.
- The release flow (release-please).
- Conventional Commits expectations.

This file used to duplicate that content; it now points to `AGENTS.md` so there's one source of truth that's also picked up by AI coding assistants and IDE agents.

For the broader Dreher.Media engineering standards (branch naming, commit format, repo configuration, semver discipline, …), see the [`Dreher-Media/standards`](https://github.com/Dreher-Media/standards) repo. External contributors: everything you need is in `AGENTS.md` already; the standards repo is internal context.
